# 헤지펀드 조직 전환 계획 (T2, 전략 C)

CCGS v1.1.1(커밋 `7ed2c3e`)의 운영 기반만 선별하여 옮기고, 헤지펀드 운용사의 에이전트 조직을 새로 구성하기 위한 계획 문서 모음입니다. 작성일은 2026년 9월 24일이며, 현재 상태는 창업자 검토용 초안입니다.

> 이 문서들은 공개 자료와 저장소 분석을 바탕으로 작성한 계획이며, 법률·세무·투자 자문이 아닙니다. 등록 요건, 겸직 가능 범위, 규제 보고 의무처럼 법률 판단이 필요한 항목은 실제 설립 과정에서 금융감독원 사전 상담과 법무법인·회계법인의 검토를 거쳐야 합니다.

## 결론 요점

- **헤지펀드는 검토 보고서의 T2(지식 서비스 조직)와 성격이 다릅니다.** 게임 도메인 콘텐츠는 T2처럼 대부분 새로 써야 합니다. 반면 의사결정 기록, 추적성, 변경 통제 같은 통제 공정은 T1(소프트웨어 조직)에 가깝기 때문에 T2에서 제거로 판정된 구성 요소 일부가 다시 필요합니다.
- **재사용 비율은 창업자의 결정에 따라 37.5%에서 67.2% 사이에서 정해집니다.**

  | 구분 | 재사용 비율 |
  |---|---|
  | 헤지펀드, 조건 없이 이식하는 구성 요소 | 87 / 232 = 37.5% |
  | 헤지펀드, 조건부 구성 요소를 모두 이식하는 경우 | 156 / 232 = 67.2% |
  | 검토 보고서 T2 (지식 서비스 조직) | 41.4% |
  | 검토 보고서 T1 (소프트웨어 제품 조직) | 70.3% |

  가장 큰 변수는 코드·모델 파이프라인이 필요한지 여부(Q25)입니다.
- **CCGS의 게이트는 권고용이므로 통제 기능은 새로 강제해야 합니다.** `strict_gate_checks`는 구현되지 않았고, 기본 검토 모드(`lean`)는 스킬별 게이트를 건너뛰며, 기본 팀 규모(`individual`)는 전문 에이전트를 가까운 핵심 에이전트로 합칩니다. 따라서 리스크(CRO)와 준법(CCO) 통제는 설정으로 생략할 수 없는 고정 좌석으로 두고, 훅으로 차단하도록 설계했습니다.
- **법정 인력은 사람이어야 합니다.** 상근 투자운용인력 3명과 준법감시인은 법령상 실제 인력이 맡아야 하므로, 에이전트는 이 직무를 보조할 뿐이며 직무를 대신하지 않습니다.
- **조직은 3단계 표준 조직도를 설계하고, 1단계 필수 역할부터 구현하는 방식을 권장합니다.** 에이전트 수는 1단계 10~13개, 2단계 22~27개, 3단계 24~31개로 추정합니다.
- **작업량은 약 201~548시간으로 추정합니다.** 조건부 확장 단계(P8)를 포함하면 약 261~748시간이며, P5 시범 구축을 마친 뒤 실제 측정값으로 다시 추정합니다.

- 설계 판단은 메인 세션(Advisor)이 내렸고, 문서 작성과 파일 분석은 서브에이전트(Worker)가 맡았습니다.
- 구성 요소 판정은 서로 독립된 검증자 7개가 인용 412건을 파일에서 직접 대조했으며, 잘못된 인용 9건을 찾아 수정했습니다. 수정 내역은 [evidence/verifier-issues.md](evidence/verifier-issues.md)에 있습니다.
- 청크 분할은 원본과 바이트 단위로 일치하는지 검사했으며, `python3 docs/hedge-fund-setup/tools/split_report.py --check`로 다시 확인할 수 있습니다.
