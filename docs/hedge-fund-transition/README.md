# 헤지펀드 조직 전환 계획 (T2, 전략 C)

CCGS v1.1.1(커밋 `7ed2c3e`)의 운영 기반만 선별하여 옮기고, 헤지펀드 운용사의 에이전트 조직을 새로 구성하기 위한 계획 문서 모음입니다. 작성일은 2026년 9월 24일이며, 현재 상태는 창업자 검토용 초안입니다.

> 이 문서들은 공개 자료와 저장소 분석을 바탕으로 작성한 계획이며, 법률·세무·투자 자문이 아닙니다. 등록 요건, 겸직 가능 범위, 규제 보고 의무처럼 법률 판단이 필요한 항목은 실제 설립 과정에서 금융감독원 사전 상담과 법무법인·회계법인의 검토를 거쳐야 합니다.

## 사명 재설정 (2026-09-24)

3라운드 논의에서 창업자는 조직의 사명을 다시 설정했습니다(DEC-09). 새 사명은 에이전트 조직이 창업자 1인(대표이자 CIO)에게 헤지펀드 조직이 만드는 모든 투자 정보를 제공하는 것입니다. 정보 영역은 리서치, 투자 방향(하우스 뷰), 리스크, 종목 피킹, 시장 분석입니다. 창업자가 모든 투자 결정을 내리고, 에이전트는 신뢰도 수준을 담은 정보와 분석과 추천을 제공할 뿐 주문을 보내지 않습니다.

조직은 이제 단계가 아니라 웨이브(wave) 단위로 가동합니다. W1 정보 핵심 웨이브는 지금 가동하며 11개 에이전트로 구성합니다: chief-of-staff, cio, cro, head-of-research, market-strategist, portfolio-manager, research-analyst, idea-screener, red-team-analyst, data-steward, trader. W2 펀드 운영 웨이브는 창업자가 펀드 설립 절차를 시작하면 가동하며 총 23개 에이전트가 됩니다(ceo-office 포함, [design-addendum-01.md](evidence/design-addendum-01.md) 정오표 01). W3 기관화 웨이브는 성장기 2단계나 3단계에 이르면 가동하며 총 29개 에이전트가 됩니다. Q25 답변이 C나 D이면 퀀트 리서치와 모델 거버넌스 에이전트를 0개에서 4개까지 추가로 가동합니다.

W1의 정보 상품은 일간 브리핑, 주간 리포트, 수시 질의응답, 이벤트 알림으로 구성합니다. 대상 시장은 국내 상장 주식을 종목 단위로 다루고, 거시 지표와 글로벌 지표를 시장 분석에 함께 사용합니다. 커버리지와 데이터 소스와 섹터 분류는 설정 데이터로 관리하므로, 이후 미국 주식으로 범위를 넓힐 수 있도록 미리 대비합니다.

모든 종목 콜과 모든 하우스 뷰 변경은 강세론과 약세론을 거쳐 CIO 종합 의견으로 마무리합니다. red-team-analyst가 약세론을 작성하고, cio가 신뢰도 수준을 담은 종합 의견을 작성하며, 최종 결정은 창업자가 내립니다.

## 결론 요점

- **헤지펀드는 검토 보고서의 T2(지식 서비스 조직)와 성격이 다릅니다.** 게임 도메인 콘텐츠는 T2처럼 대부분 새로 써야 합니다. 반면 의사결정 기록, 추적성, 변경 통제 같은 통제 공정은 T1(소프트웨어 조직)에 가깝기 때문에 T2에서 제거로 판정된 구성 요소 일부가 다시 필요합니다.
- **재사용 비율은 창업자의 결정에 따라 37.5%에서 67.2% 사이에서 정해지며, 결정을 반영한 결과는 41.8%입니다.** 조건부 구성 요소 69개를 결정에 맞추어 판정한 결과, 10개는 수정 이식(TAKE-MODIFY), 43개는 제외(LEAVE), 16개는 W2 가동이나 P2 설계에서 정하는 보류(DEFERRED)가 되었습니다([TRANSPLANT-MANIFEST.md](TRANSPLANT-MANIFEST.md) 10절). 보류 항목을 모두 이식하면 48.7%입니다.

  | 구분 | 재사용 비율 |
  |---|---|
  | 헤지펀드, 조건 없이 이식하는 구성 요소 | 87 / 232 = 37.5% |
  | 헤지펀드, 조건부 구성 요소를 모두 이식하는 경우 | 156 / 232 = 67.2% |
  | 헤지펀드, 창업자 결정 반영 후 | 97 / 232 = 41.8% (보류 항목까지 이식하면 113 / 232 = 48.7%) |
  | 검토 보고서 T2 (지식 서비스 조직) | 41.4% |
  | 검토 보고서 T1 (소프트웨어 제품 조직) | 70.3% |

  가장 큰 변수는 코드·모델 파이프라인이 필요한지 여부(Q25)였으며, 창업자가 분석 코드만 두기로 결정했으므로(DEC-29) 재사용 비율은 T2와 비슷한 수준이 되었습니다.
- **CCGS의 게이트는 권고용이므로 통제 기능은 새로 강제해야 합니다.** `strict_gate_checks`는 구현되지 않았고, 기본 검토 모드(`lean`)는 스킬별 게이트를 건너뛰며, 기본 팀 규모(`individual`)는 전문 에이전트를 가까운 핵심 에이전트로 합칩니다. 따라서 리스크(CRO)와 준법(CCO) 통제는 설정으로 생략할 수 없는 고정 좌석으로 두었습니다(DEC-18). 차단 방식은 창업자의 결정(DEC-17)에 따라 훅 대신 CRO 에이전트의 판정과 창업자의 승인 기록으로 운영하며, 승인 기록이 없는 통제 결정은 NOT ASSESSED로 표시합니다. 실자본을 운용하기 전에 훅 기반 차단을 다시 검토합니다.
- **법정 인력은 사람이어야 합니다.** 상근 투자운용인력 3명과 준법감시인은 법령상 실제 인력이 맡아야 하므로, 에이전트는 이 직무를 보조할 뿐이며 직무를 대신하지 않습니다.
- **조직은 이제 3단계가 아니라 웨이브 단위로 가동합니다.** 에이전트 수는 W1 11개, W2까지 23개, W3까지 29개이며, Q25 조건에 따라 0~4개를 추가로 가동합니다.
- **작업량은 약 201~548시간으로 추정합니다.** 조건부 확장 단계(P8)를 포함하면 약 261~748시간입니다. 창업자가 주당 40시간 이상을 투입하므로(DEC-37) 핵심 작업은 약 5~14주가 걸리며, P5 시범 구축을 마친 뒤 실제 측정값으로 다시 추정합니다.
