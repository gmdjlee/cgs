# CCGS 조직 전환 검토

Claude Code Game Studios v1.1.1(커밋 `7ed2c3e`)을 게임 스튜디오가 아닌 조직으로 옮길 수 있는지 검토한 보고서입니다. 분석일은 2026년 9월 24일입니다.

- 보고서: [index.html](index.html). 내려받아 브라우저로 열면 차트와 상세 매핑 표를 볼 수 있습니다.
- 게시본: <https://claude.ai/artifact/R4N8NZwhzVejUFjNgJYZhu>. 소유자와 공유받은 사람만 열 수 있습니다.

## 결론

| 대상 조직 | 재사용 비율 (개수 / 줄 수) | 성격 | 권장 전략 | 예상 작업량 |
|---|---|---|---|---|
| T1 소프트웨어 제품 조직 (SaaS·앱 개발팀) | 70.3% / 66.9% | 개조 | 포크 후 단계적 전환 | 최소 90~230시간, 전체 200~540시간 |
| T2 지식 서비스 조직 (에이전시·컨설팅) | 41.4% / 32.4% | 재구축 | 운영 기반만 선별 이식 | 250~700시간 |

## 요점

- 운영 기반(훅, 설정 해석기, 세션 상태, 게이트 장치, 스킬 테스트)은 게임과 거의 무관합니다.
- 전달 공정(ADR → 에픽 → 스토리 → 구현 → 리뷰 → 출시)은 일반적인 소프트웨어 공정입니다. GDD 입력과 엔진 전문가 라우팅만 바꾸면 됩니다.
- 게임과의 결합은 설계 단계 스킬, 에이전트의 도메인 지식, 엔진 전문가 15개, 템플릿에 모여 있습니다.
- 경로 이름만 바꾸면 오류 없이 기능이 꺼지는 곳이 13군데 있습니다. 전환할 때는 보고서의 '조용히 깨지는 지점' 목록을 점검표로 사용해야 합니다.
